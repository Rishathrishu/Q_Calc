⚙️ Q_Calc – Java-Based Calculator Application

Q_Calc is a Java-based calculator project developed to gain hands-on experience with core Java programming concepts and Gradle-based project setup. The application implements fundamental arithmetic operations and serves as a foundation for understanding Java syntax, logic building, and debugging techniques.

🚀 Key Highlights

Project Setup with Gradle: Created and managed a Java project using Gradle, demonstrating familiarity with modern build automation tools.

Core Feature Implementation: Developed essential calculator functionalities, including arithmetic operations such as addition, subtraction, multiplication, and division.

Bug Identification & Fixing: Debugged and resolved logical and runtime issues in newly implemented calculator features to ensure optimal performance and accuracy.

Hands-on Java Practice: Strengthened understanding of variables, data types, control structures, and methods through practical application.

🧩 What I Learned

Setting up and managing Java projects using Gradle.

Implementing modular and reusable code components.

Applying debugging and testing practices to ensure code correctness.

Reinforcing fundamental programming and logical problem-solving skills.
